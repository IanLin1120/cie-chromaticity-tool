# CIE 色度圖工具

CIE 1931 xy 色度圖的網頁工具，可以用 Edge／Chrome **安裝成桌面應用程式**（PWA），有自己的視窗、桌面捷徑和開始功能表圖示。第一次開啟後也可以離線使用。

**開啟網址：** https://ianlin1120.github.io/cie-chromaticity-tool/

## 功能

| 分頁 | 內容 |
|---|---|
| 1 色點查詢 | 輸入 x、y，在色度圖上標出位置，並顯示 HEX 色碼、Excel 自訂色彩 RGB、VBA 色彩值、u′v′、主波長、色純度、色溫 |
| 2 規格框繪製 | 輸入 x、y 上下限畫出規格框；可調整顯示範圍；輸出 PNG／JPG／SVG 高清圖 |
| 3 量測數據判定 | 匯入 Excel／CSV 或貼上數據；計算平均、最大、最小、標準差；超規的數值標紅；輸出含色度圖的 Excel 報告 |

色度圖選項：網路常見樣式／精準 sRGB 色彩、Kelly 色區分界線與名稱、黑體軌跡、標準光源 A／B／C／D65／E、波長標示、中文／English 圖面文字。

## 安裝到 Windows 桌面（Edge）

1. 用 Edge 開啟上面的網址。
2. 點頁面右上角的「**安裝到電腦**」按鈕。或者點網址列右側的「應用程式可用」圖示，也可以從 Edge 選單 **⋯ → 應用程式 → 將此網站安裝為應用程式**。
3. 安裝完成後，會出現在「開始」功能表和桌面，可以釘選到工作列。

移除方式：在應用程式視窗右上角點 **⋯ → 解除安裝**，或到 Windows「設定 → 應用程式」移除。

## 更新

修改 `index.html` 並推送到 GitHub 後，已安裝的應用程式下次連網開啟時會自動載入新版。如果有改到 `sw.js` 或函式庫，記得把 `sw.js` 裡的 `VERSION` 加 1。

## 檔案

```
index.html             主程式（單一檔案）
manifest.webmanifest   應用程式名稱、圖示、顏色設定
sw.js                  Service Worker（離線快取）
icons/                 應用程式圖示
```

## 備註

- 所有資料都在瀏覽器內處理，不會上傳。
- 色碼以 sRGB（D65）換算；「網路常見樣式」的底色只是為了好看，不是真實色彩。
- Kelly（1943）色區分界線是依常見的色名分區圖描繪，再校正到正確的光譜軌跡上，約有 ±0.01 的誤差，僅供目視參考。
